# ЖИ-детектив / ИИ-детектив

Интеллектуальная игра на 15 минут для семинара «Жасанды интеллект заманындағы мектеп кітапханасы: Жаңа мүмкіндіктер мен сын-қатерлер». Вопросы на казахском и русском, 10 вопросов в 3 раундах.

| Файл | Зачем |
|---|---|
| `wayground_import.xlsx` | Импорт вопросов в Wayground: Create → Assessment → Import → Spreadsheet |
| `host_guide.md` | Шпаргалка ведущего: сценарий по минутам, ответы, пояснения, источники |
| `backup.html` | Запасная версия для проектора без интернета и телефонов (открыть в браузере, листать стрелками) |
| `build.py` | Все вопросы хранятся здесь. После правки: `python3 build.py` |

Если Wayground не примет таблицу, скачайте его шаблон в окне импорта и скопируйте туда столбцы. Другой вариант — загрузить `host_guide.md` через Wayground AI import.
